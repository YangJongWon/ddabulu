# Ddabulu (따블루)

**한국어** · [English](README.en.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md)

> 그거, 이미 집에 있어요.

쇼핑 중인 상품이 **이미 산 물건과 겹치는지** 바로 알려 주는 Chrome 확장입니다. 같은 상품을 또 사거나, 비슷한 걸 모르고 하나 더 사거나, 같은 사람에게 같은 선물을 두 번 하는 일을 막아 줍니다.

| 이미 산 상품 | 비슷한 상품 | LINE 스탬프 겹침 |
|---|---|---|
| ![이미 산 상품](docs/duplicate.png) | ![비슷한 상품](docs/similar.png) | ![LINE 스탬프 겹침](docs/line-overlap.png) |

<sub>스크린샷은 이전 버전이라 지금 화면과 문구가 조금 다를 수 있습니다.</sub>

## 주요 기능

### 이미 산 물건 알림
- 상품 페이지를 열면 내가 기록한 물건과 비교해서, 겹치면 화면 오른쪽 아래에 카드로 알려 줍니다.
- **같은 상품**(같은 상품 번호·주소)은 100%로, 다른 쇼핑몰의 같은 상품이나 비슷한 상품은 점수로 보여 줍니다.
  - 90% 이상 **거의 같은 상품** · 70% 이상 **매우 비슷** · 50% 이상 **같은 종류**
- 점수는 카테고리, 상품명, 브랜드, 쇼핑몰, 용량, 색상, 사이즈, 가격, **상품 이미지**를 함께 비교해서 냅니다. 항목마다 "detail"을 누르면 어떤 근거로 몇 점이 나왔는지 볼 수 있습니다.
- 상품 종류에 따라 비교 기준이 달라집니다. 옷·신발은 색상과 사이즈를, 스탬프·이모티콘은 그림을 더 중요하게 봅니다.

### LINE 스탬프 하나하나 비교
- 스탬프 묶음을 열면 안에 든 스탬프를 하나씩, 이미 가진 묶음들의 스탬프와 그림으로 비교합니다.
- "88개 중 16개는 이미 있어요", 겹치는 비율, **중복으로 내게 될 금액**을 보여 주고, 페이지의 스탬프마다 닮은 정도를 표시합니다.

### 선물 기록
- "선물했어요"로 **누구에게 무엇을 줬는지** 기록합니다.
- 같은 사람에게 같은 걸 또 주려 하면 알려 줍니다. 다른 사람에게 준 건 겹침으로 보지 않습니다.

### 후보 담기
- 사지 않았지만 고민 중인 상품을 **후보**로 담아 둡니다. 나를 위한 후보도, "민수에게 줄 후보"도 담을 수 있습니다.
- 후보마다 **이미 가진 물건(선물 후보는 그 사람이 받은 선물)과 겹치는지** 표시해서, 안 겹치는 후보를 골라 살 수 있습니다.
- 후보를 실제로 사거나 선물하면 후보에서 기록으로 자동으로 옮겨집니다.

### 겹치지 않는 다른 선택
- 겹치는 상품을 보고 있을 때, 다른 사용자들이 함께 본 상품 중 **내 물건과 겹치지 않는 것**을 추천합니다.
- 추천표는 통째로 내려받아 **브라우저 안에서** 고르기 때문에, 내가 무엇을 보고 있는지는 서버에 전해지지 않습니다. (추천 서비스는 준비 중입니다.)

### 그 밖에
- **목록 공유:** 내 물건·선물 목록이나 경고 카드를 이미지로 만들어 복사·저장합니다.
- **내보내기·가져오기:** 기록을 JSON 파일로 백업하고 옮깁니다. 기간·MY/선물별로 골라 내보낼 수 있습니다.
- **표시 끄기:** 며칠 동안, 또는 특정 사이트에서 알림을 끌 수 있습니다.
- **4개 언어:** 한국어, English, 日本語, 简体中文. 브라우저 언어를 따르거나 직접 고를 수 있습니다.

## 설치

- **Chrome 웹 스토어:** 준비 중입니다.
- **직접 설치:**
  1. 이 저장소를 내려받습니다 (`Code → Download ZIP` 또는 `git clone`).
  2. Chrome에서 `chrome://extensions`를 열고 오른쪽 위 **개발자 모드**를 켭니다.
  3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `extension/` 폴더를 고릅니다.

## 개인정보

- 구매 기록, 선물 받는 사람, 후보, 메모는 **모두 내 브라우저 안(`chrome.storage.local`)에만** 저장됩니다. 서버로 보내지 않습니다.
- 처음 설치할 때 **익명 사용 통계**를 보낼지 묻습니다. 동의하지 않아도 모든 기능을 똑같이 쓸 수 있고, 환경설정에서 언제든 바꿀 수 있습니다.
- 통계에는 URL, 내 물건 목록, 받는 사람 이름이 들어가지 않으며, 고정된 사용자 ID도 없습니다. 보내는 항목은 [`extension/lib/telemetry.js`](extension/lib/telemetry.js) 한 파일에 정해져 있고, 환경설정에서 보내기 전 데이터를 그대로 볼 수 있습니다.
- 자세한 내용: [개인정보처리방침](docs/PRIVACY.md)

## 개발

```
extension/
  manifest.json        확장 설정
  background.js        기록 저장, 비교, 이미지 해시, 통계 대기열
  content.js           쇼핑 페이지의 경고 카드
  popup.html/js/css    확장 아이콘 팝업 (기록, 목록, 환경설정, 동의)
  lib/extract.js       페이지에서 상품 정보 읽기
  lib/similarity.js    상품 비교와 점수
  lib/bundle.js        LINE 스탬프 그림 비교
  lib/recs.js          겹치지 않는 추천 고르기
  lib/telemetry.js     익명 통계의 전체 항목과 동의 처리
  lib/i18n.js          한·중·일·영 문구
  lib/share.js         목록 공유 이미지
  tests/               테스트
```

테스트 (Node 22 이상, 추가 설치 없음):

```sh
node --test extension/tests/*.cjs
```
