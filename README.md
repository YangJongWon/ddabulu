# Ddabulu (따블루)

쇼핑 중인 상품이 이미 산 물건과 겹치는지 바로 알려 주는 Chrome 확장입니다.

- 같은 상품, 비슷한 상품(이름·카테고리·브랜드·용량·색상·이미지 비교), LINE 스탬프 묶음 겹침을 알려 줍니다.
- 선물한 물건도 받는 사람별로 기억해서, 같은 사람에게 같은 선물을 두 번 하지 않게 합니다.
- 사지 않은 상품은 후보로 담아 두고, 가진 물건과 겹치지 않는 후보를 고를 수 있습니다.
- 기록은 모두 브라우저 안(`chrome.storage.local`)에만 저장됩니다. 익명 통계는 사용자가 동의한 경우에만 보내며, 무엇을 보내는지는 [`extension/lib/telemetry.js`](extension/lib/telemetry.js) 한 파일에 정해져 있습니다. 자세한 내용은 [개인정보처리방침](docs/PRIVACY.md)을 보세요.

## 개발

1. Chrome에서 `chrome://extensions`를 열고 개발자 모드를 켭니다.
2. "압축해제된 확장 프로그램을 로드합니다"로 `extension/` 폴더를 고릅니다.

테스트 (Node 22 이상):

```sh
node --test extension/tests/*.cjs
```
