# Ddabulu(ダブる)

[한국어](README.md) · [English](README.en.md) · **日本語** · [简体中文](README.zh-CN.md)

> それ、もう家にありますよ。

見ている商品が**もう持っている物とダブっていないか**、商品ページですぐに知らせる Chrome 拡張機能です。同じ物をまた買ったり、似た物をうっかりもう一つ買ったり、同じ人に同じプレゼントを二度贈ったりするのを防ぎます。

## 主な機能

### もう持っている物のお知らせ
- 商品ページを開くと、記録した持ち物と比べて、ダブっていれば画面右下にカードで知らせます。
- **同じ商品**(同じ商品番号・アドレス)は 100%、他のショップの同じ商品や似た商品はスコアで表示します。
  - 90% 以上 **ほぼ同じ商品** · 70% 以上 **とても似ている** · 50% 以上 **同じ種類**
- スコアはカテゴリ、商品名、ブランド、ショップ、容量、色、サイズ、価格、**商品画像**をあわせて比べて出します。各項目の「detail」を押すと、何を根拠に何点になったかが見られます。
- 商品の種類で比べ方が変わります。服や靴は色とサイズを、スタンプや絵文字は絵をより重く見ます。

### LINE スタンプを一つずつ比較
- スタンプのセットを開くと、中のスタンプを一つずつ、持っているセットのスタンプと絵で比べます。
- 「88 個中 16 個はもう持っています」、ダブりの割合、**ダブりに払うことになる金額**を表示し、ページ上の各スタンプに似ている度合いを表示します。

### プレゼントの記録
- 「プレゼントした」で**誰に何を贈ったか**を記録します。
- 同じ人に同じ物をまた贈ろうとすると知らせます。他の人に贈った物はダブりとみなしません。

### 候補
- まだ買っていない、検討中の商品を**候補**に入れておけます。自分用の候補も、「〇〇へのプレゼント候補」も入れられます。
- 候補ごとに**持っている物(プレゼント候補はその人が受け取った物)とダブるか**を表示するので、ダブらない候補を選んで買えます。
- 候補を実際に買ったり贈ったりすると、候補から記録へ自動で移ります。

### ダブらない他の選択肢
- ダブる商品を見ているとき、他のユーザーが一緒に見た商品のうち**自分の持ち物とダブらないもの**をおすすめします。
- おすすめの表は丸ごとダウンロードして**ブラウザの中で**選ぶので、何を見ているかはサーバーに伝わりません。(おすすめサービスは準備中です。)

### その他
- **リストの共有:** 持ち物・プレゼントのリストやお知らせカードを画像にしてコピー・保存できます。
- **エクスポート・インポート:** 記録を JSON ファイルでバックアップ・移行できます。期間や自分用/プレゼント別に選べます。
- **非表示:** 数日間、または特定のサイトでお知らせを止められます。
- **4 言語:** 韓国語、英語、日本語、簡体字中国語。ブラウザの言語に合わせるか、自分で選べます。

## 対応ショップ

専用ルールがあるショップ:

| ショップ | 備考 |
|---|---|
| LINE STORE | スタンプ(絵を一つずつ比較)、絵文字 |
| カカオ絵文字ショップ | 韓国 |
| Coupang · NAVER スマートストア/ブランドストア · 11番街 · Gマーケット · MUSINSA | 韓国 |
| Amazon | 各国のサイトすべて |

そのほか、商品情報(schema.org の `Product` または `og:type=product`)を持つほとんどのショップで動きます。

## インストール

- **Chrome ウェブストア:** 準備中です。
- **ソースから:**
  1. このリポジトリをダウンロードします(`Code → Download ZIP` または `git clone`)。
  2. Chrome で `chrome://extensions` を開き、右上の**デベロッパー モード**をオンにします。
  3. **パッケージ化されていない拡張機能を読み込む**を押して `extension/` フォルダを選びます。

## プライバシー

- 購入記録、プレゼントの相手、候補、メモは**すべて自分のブラウザの中(`chrome.storage.local`)だけ**に保存されます。サーバーには送りません。
- 初めてインストールしたとき、**匿名の利用統計**を送るかどうかを聞きます。同意しなくてもすべての機能を同じように使え、設定でいつでも変えられます。
- 統計には URL、持ち物リスト、相手の名前は含まれず、固定のユーザー ID もありません。送る項目はすべて [`extension/lib/telemetry.js`](extension/lib/telemetry.js) の 1 ファイルで決まっていて、設定画面で送信前のデータをそのまま見られます。
- 詳しくは: [プライバシーポリシー](docs/PRIVACY.md)(韓国語)

## 開発

```
extension/
  manifest.json        拡張機能の設定
  background.js        記録の保存、比較、画像ハッシュ、統計の送信待ち
  content.js           ショップのページに出るお知らせカード
  popup.html/js/css    ツールバーのポップアップ(記録、リスト、設定、同意)
  lib/extract.js       ページから商品情報を読む
  lib/similarity.js    商品の比較とスコア
  lib/bundle.js        LINE スタンプの絵の比較
  lib/recs.js          ダブらないおすすめを選ぶ
  lib/telemetry.js     匿名統計の全項目と同意の扱い
  lib/i18n.js          韓・中・日・英の文言
  lib/share.js         共有用のリスト画像
  tests/               テスト
```

テスト(Node 22 以上、追加インストール不要):

```sh
node --test extension/tests/*.cjs
```
