# Ddabulu(따블루) 개인정보처리방침 (초안)

시행일: 2026-__-__ · 동의 문구 버전 1

Ddabulu는 쇼핑 중인 상품이 이미 산 물건과 겹치는지 알려 주는 브라우저 확장입니다. 구매 목록, 선물 받는 사람, 메모 같은 기록은 **사용자의 브라우저 안(`chrome.storage.local`)에만 저장**되며 외부로 보내지 않습니다.

아래 내용은 사용자가 **직접 동의한 경우에만** 적용됩니다. 동의하지 않아도 모든 기능을 똑같이 쓸 수 있습니다.

## 1. 수집 항목

### 익명 사용 통계 (선택 동의)

| 구분 | 보내는 것 | 보내지 않는 것 |
|---|---|---|
| 상품 인식 | 사이트 주소의 호스트(예: `coupang.com`), 경로 형태(예: `/vp/products/{n}`), 필드별 인식 성공 여부, 인식에 쓴 방식, 이미지 개수 | 전체 URL, 쿼리스트링, 상품 번호, 상품명(피드백·이어 본 상품에서만 보냄, 아래 참고) |
| 중복 판정 | 판정 건수, 최고 점수, 요인별 점수(이름·카테고리·이미지 등 0~100), 사용자 피드백(맞음/틀림) | 비교 대상인 내 물건의 이름·URL·사진 |
| 피드백 시 상품명 | 사용자가 "맞아요/아니에요"를 누른 경우에만, **보고 있는 페이지에 표시된 상품명**(최대 80자) | 내 물건·선물의 이름, 상품명 속 이메일·전화번호·6자리 이상 숫자, 건강·의료·성인 관련 상품의 이름 |
| 이어서 본 상품 | 30분 안에 **같은 쇼핑몰이나 같은 상위 카테고리**에서 연달아 본 상품 두 개의 이름과 카테고리 상위 2단계, 각 상품이 내 물건과 겹쳤는지 여부, 두 번째 상품의 호스트 | 내 물건·선물의 이름, 세 개 이상 이어진 열람 순서, 민감 상품(어느 한쪽이라도 해당하면 짝 전체를 보내지 않음) |
| 기록 | 내 물건/선물/후보 구분, 중복 여부, 카테고리 상위 2단계, 가격 자릿수 | 가격, 받는 사람, 메모, 구매 목록 |
| 공통 | 날짜(일 단위), 확장 버전, 언어 | 시각, 기기·사용자 식별자, 쿠키 |
| 선택 입력 | 연령대(14~19세, 20대 … 60대 이상), 성별 | 생년월일, 정확한 나이 |

- 고정된 사용자 ID를 만들지 않습니다. 여러 이벤트를 모아 한 번에 보내므로 한 묶음 안의 이벤트는 같은 브라우저에서 왔다는 것만 알 수 있습니다.
- 서버는 접속 IP를 저장하지 않습니다.
- 만 14세 미만의 연령대는 받지 않습니다.
- 바로 전에 본 상품은 짝을 만들기 위해 브라우저 세션 저장소에만 잠시 두며, 브라우저를 닫으면 지워집니다.
- 실제로 전송 대기 중인 데이터는 확장 팝업 → 환경설정 → 익명 통계에서 그대로 볼 수 있습니다.

## 2. 이용 목적

- 상품 인식과 중복 판정 알고리즘의 정확도 개선
- 쇼핑 카테고리·연령대별 통계 분석을 통한 기능 개선
- **"겹치지 않는 다른 선택" 추천** (아래 참고)

### 추천에 쓰는 방식

- 서버는 이어서 본 상품 짝과 피드백을 모아 **"함께 많이 본 상품", "카테고리·연령대별로 많이 본 상품" 집계표**를 하루 한 번 만들어 공개합니다.
- 집계표에는 상품명, 카테고리, 횟수만 들어가며, 여러 날에 걸쳐 일정 횟수 이상 나온 항목만 실립니다. 민감 카테고리는 싣지 않습니다.
- 확장은 이 집계표 **전체를 내려받아 브라우저 안에서** 지금 보는 상품과 맞는 항목을 고릅니다. 무엇을 보고 있는지, 연령대가 무엇인지는 서버에 묻지 않습니다.
- 이미 가진 물건이나 지금 보는 상품과 같은 상품은 추천에서 뺍니다.
- 추천은 통계 동의 여부와 관계없이 모든 사용자에게 보일 수 있으며, 연령대·성별을 입력한 사용자에게는 해당 집계가 먼저 보입니다. 추천 링크는 쇼핑 검색 페이지로 연결되며 제휴 링크가 아닙니다.

### 학습 모델의 상업적 활용 (선택 동의, 별도)

위 통계로 학습한 **인식·추천 모델**을 제3자에게 제공하거나 판매할 수 있습니다.

- 제공하는 것은 학습된 모델이며, **수집한 원본 데이터는 제공하거나 판매하지 않습니다.**
- 모델이 개별 데이터를 기억해 재현하지 않도록 집계된 데이터로 학습합니다.
- 이 항목에 동의하지 않은 사용자의 데이터는 상업용 모델 학습에서 제외합니다.

광고 타기팅이나 맞춤형 광고에는 사용하지 않습니다.

## 3. 보관 기간

수집일로부터 365일간 보관 후 파기합니다. 고정 식별자가 없으므로 이미 전송된 데이터는 특정 사용자의 것으로 골라 삭제할 수 없습니다.

## 4. 동의 철회

팝업 → 환경설정 → 익명 통계에서 언제든 끌 수 있습니다. 끄는 즉시 전송 대기 중인 데이터도 지워집니다.
